产品介绍支持隐私服务条款

支持与问题反馈

先确认连接状态

连接过期时使用客户端的 OAuth 重新授权入口。请勿把密码、验证码、API Key 或访问令牌发到聊天或支持工单。

常见问题

  • 匹配仍在准备：稍后重试，避免重复创建需求。
  • 交换申请冲突：刷新当前状态，重新查看联系方式版本后再决定。
  • 没有绑定邮箱：可查询当前需求和交换申请；更换浏览器或清除浏览器状态可能影响账号恢复。
  • 撤回联系方式授权：可阻止后续读取，但不能收回对方已经复制的信息。

插件源码问题

可在 ChatGPT 插件 Issues 或 Grok Bot 插件 Issues 报告不含私密数据的源码问题。这不等于已经建立了账号恢复或数据删除的私密支持渠道。

服务支持

发布阻塞项：尚未确认可工作的支持邮箱或工单入口、处理责任人及支持语言。不得把本地草稿当作已上线的支持页。

正式上线前需要确定账号恢复、数据访问/删除请求及滥用举报的实际受理流程。
